## Other entrypoints

- `/`: public shell only; no private scan data embedded. Local JS/CSS/vendor assets under `/static/` are public and pinned in the asset manifest.
- `/ws/telemetry`: Host/Origin check, first-message token, authentication timeout, session expiry/revocation checks, bounded subscribers and sends. Local operator may see all local jobs; frontend filters static job events by scan ID. Not tenant isolation.
- `/docs`, `/redoc`, `/openapi.json`: middleware-protected framework endpoints; not publicly accessible without bearer authentication.
- CLI: local operator authority; offline flag and explicit provider approval. Does not inherit the web sandbox automatically.

No registration, password reset, MFA, payment, webhook or GraphQL execution routes were invented. These are not implemented product workflows.
