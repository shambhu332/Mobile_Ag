Exported Content Provider with SQL Injection Vulnerability

com.vulnerable.bank.provider.AccountProvider (line 42)

Threat Mechanics & Root Cause

The ContentProvider specifies android:exported="true" without requiring read/write permissions. User input passed to query() is concatenated directly into the raw SQL query without parameterization, allowing external malicious apps to extract sensitive account data.

Remediation Guidance

Either set android:exported="false" if external access is not required, or enforce custom signature permissions. Replace string concatenation with parameterized selection arguments (selectionArgs).
